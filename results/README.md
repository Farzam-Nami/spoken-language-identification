# Recorded experimental results

The CSV tables contain the recorded numeric metrics from the original notebook outputs (full displayed precision where available). The cluster composition table transcribes the printed class counts. Figures are extracted directly from the original embedded PNG outputs without modification.

- `classification_results_summary.csv`: accuracy, macro and weighted precision, recall and F1.
- `clustering_results_summary.csv`: custom silhouette-like score and cluster purity.
- `cluster_composition.csv`: counts by language and cluster.
- `figures/`: duration histogram, three confusion matrices, elbow curve and two PCA projections.

Running the classification and clustering notebooks writes their summary CSVs to this directory. The evaluation notebook loads those CSVs. The cluster composition CSV and extracted figures are reference artifacts; they are not automatically regenerated by the current code. No raw predictions, full feature matrix or audio is included.
